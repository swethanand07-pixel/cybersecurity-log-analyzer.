# Cybersecurity Log Analyzer

## Project Overview
A web-based cybersecurity log analyzer
that identifies and classifies security
events using sample log entries.

## Objectives
- Analyze security logs.
- Identify suspicious activities.
- Classify security events.
- Display risk levels.
- Improve security monitoring awareness.

## Technologies Used
- HTML
- CSS
- JavaScript
- GitHub Pages

## Features
- Security dashboard
- Log analysis
- Risk classification
- Sample log generation
- Analysis results table

## Testing
Tested using sample security logs
including SUCCESS, WARNING, HIGH and INFO.

## Conclusion
This project demonstrates basic
cybersecurity log monitoring and
security event classification.
