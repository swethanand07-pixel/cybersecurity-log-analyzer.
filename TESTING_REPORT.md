
# CYBERSECURITY LOG ANALYZER
## TESTING REPORT

### 1. Project Overview
The Cybersecurity Log Analyzer is a web-based application designed to analyze sample security logs and classify security events.

### 2. Testing Objectives
- Verify log analysis functionality.
- Identify security event categories.
- Check dashboard statistics.
- Verify sample log loading.
- Test the Clear button.

### 3. Test Cases

| Test Case | Expected Result | Status |

| Load Sample Logs | Sample logs displayed | Pass |
| Analyze Logs | Logs classified | Pass |
| Successful Login | SUCCESS | Pass |
| Multiple Login Attempts | WARNING | Pass |

| Unauthorized Access | HIGH | Pass |

### 4. Technologies Used
- HTML
- CSS
- JavaScript

### 5. Conclusion
The Cybersecurity Log Analyzer successfully demonstrates basic security event classification using sample log entries. It provides an educational demonstration of security monitoring.
